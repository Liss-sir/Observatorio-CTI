# Observatorio-CTI

Observatorio de Perfiles Tecnológicos. Análisis de necesidades empresariales clasificadas por líneas tecnológicas y tecnologías emergentes del sector productivo risaraldense.

---

## Descripción

**Observatorio-CTI** es un proyecto orientado al análisis, clasificación y visualización de necesidades tecnológicas empresariales del sector productivo del departamento de Risaralda.

El sistema permite recopilar información estratégica proveniente de empresas, organizarla por líneas tecnológicas y tecnologías emergentes, y generar insumos para la toma de decisiones académicas, investigativas y de formación.

La plataforma busca centralizar y estructurar la información del entorno productivo regional, facilitando la identificación de tendencias, brechas tecnológicas y oportunidades de innovación.

---

## Objetivos del Sistema

- Identificar necesidades tecnológicas del sector empresarial.
- Clasificar necesidades por líneas tecnológicas.
- Analizar tecnologías emergentes relevantes para la región.
- Generar información estratégica para planeación académica.
- Consolidar datos para la toma de decisiones institucionales.

---

## Características

- Registro y gestión de empresas.
- Captura estructurada de necesidades técnicas.
- Clasificación por líneas tecnológicas.
- Identificación de tecnologías emergentes.
- Panel de visualización de estadísticas.
- Consulta segmentada de información.
- Gestión de usuarios y roles.
- Arquitectura modular y escalable.

## Instalación

### Requisitos previos

- Servidor local (XAMPP, WAMP o similar)
- PHP 8.x
- MySQL / MariaDB
- Navegador web moderno

---

### Pasos de instalación

1. Clonar el repositorio:
  git clone https://github.com/TU-USUARIO/Observatorio-CTI.git

2. Copiar el proyecto en el directorio del servidor local:
   
  htdocs/ (XAMPP)

  www/ (WAMP)

4. Importar la base de datos en phpMyAdmin.

5. Configurar las credenciales de conexión en:
  config/database.php

  Ejemplo:
  
    $host = 'localhost';
    $dbname = 'observatorio_cti';
    $user = 'root';
    $pass = 'Tu_contraseña_mysql';

5. Iniciar el servidor local.

6. Acceder desde el navegador:
  http://localhost/Observatorio-CTI/
